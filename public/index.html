명령어설명사용 예시
/join #채널 [암호]채널 개설 및 즉시 입장 (암호 채널 대응)/join #개발 mykey123
/part (또는 /leave)현재 채널에서 퇴장/part
/list현재 서버 채널 목록 탐색 창 열기/list
/servers (또는 F2)화이트리스트 다중 서버 리스트 및 공개채널 탐색 창 열기/servers
/server <주소> [#채널]다른 서버 및 채널로 동시 접속 창 열기/server https://c.org #게임채널
/topic <주제>채널 주제(Topic) 변경 (+t 방장 전용)/topic 오늘 밤 9시 쇼기 대국!
/mode #채널 [+/-모드] [인자]채널 모드 설정 (+i,+t,+k,+l,+m,+n,+p,+s,+o,+v)/mode #개발 +m / /mode #개발 +k pw123
/invite <닉네임> [#채널]초대 전용(+i) 채널에 사용자 초대/invite 코딩고양이
/op <닉네임>다른 유저에게 방장(@) 권한 부여 (+o)/op 코딩고양이
/deop <닉네임>유저의 방장(@) 권한 회수 (-o)/deop 코딩고양이
/kick <닉네임> [사유]채널 내 유저 퇴장 조치 (방장 전용)/kick 악성유저 도배 금지
/nick <닉네임>내 닉네임 실시간 변경 (선점 확인)/nick 코딩고양이
/nickpass <암호>닉네임 비밀번호 등록/인증 (사칭 방지 보호)/nickpass mysecret123
/identify <암호>보호된 닉네임 본인 인증 (사칭 방어 해제)/identify mysecret123
/me <행동>액션 감정표현 메시지/me 손을 흔들며 인사합니다
/clear현재 대화창 내용 비우기/clear
/export현재 방의 로컬 대화 백업(.txt) 다운로드/export
/whois <닉네임> (또는 /w)사용자 상세 정보(연결 주소, 입실 채널, 잠수 시간 등) 조회/whois 코딩고양이
/help이 도움말 안내창 열기/help

👑 서버 총괄 관리자(Operator) 전용 명령어

명령어설명사용 예시
/oper <아이디> <암호>서버 총괄 관리자(Operator) 권한 인증/oper admin secret
/servername <이름>서버 표시 이름 변경 (예: A서버, C서버)/servername C서버
/serverurl <주소>서버 공개 접속 주소 설정/serverurl https://c.org

/banlist서버 전체 차단 목록(영구 및 임시 하루 밴) 조회/banlist
/ban <닉네임> [사유]악성 사용자 영구 IP 차단 및 강제 퇴장/ban 악성유저
/unban <닉네임 또는 IP>차단된 사용자 또는 IP 차단 해제/unban 1.2.3.4 / /unban 유저닉네임
